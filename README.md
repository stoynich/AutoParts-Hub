# AutoParts Hub — Система управления складом автозапчастей

## Описание проекта
Система управления складом для дистрибьютора автозапчастей.  
Обеспечивает учёт по OEM и кросс-номерам, VIN-привязку совместимости, зональное хранение с ABC-анализом и комплектацию заказов.

## Технические требования
- Java 17+
- Git / GitHub
- IntelliJ IDEA


## Функциональные требования

### Основные сущности
- **AutoPart** — запчасть (артикул, название, OEM, категория, производитель, кросс-номера, цена, вес, ABC-категория)
- **StorageZone** — зона хранения (ID, название, тип зоны, ABC-категория, вместимость, загрузка, грузоподъёмность)
- **Supplier** — поставщик (название, ИНН, контакты, категории поставок, срок поставки, рейтинг)
- **PartBatch** — партия запчастей (ID, запчасть, количество, дата приёмки, срок годности, сертификат, страна, зона)
- **CustomerOrder** — заказ клиента (ID, внешний ID, клиент, статус, приоритет, позиции, VIN, вес, трек-номер)
- **OrderLine** — позиция заказа (запчасть, количество, цена, запрошенный OEM, выданный OEM)

### Бизнес-правила
1. **Контроль остатков** — нельзя продать больше, чем есть в наличии (проверка при резервировании, FEFO для расходников)
2. **VIN-привязка** — запчасть проверяется на совместимость с VIN автомобиля перед добавлением в заказ
3. **ABC-анализ зон** — A-категория (оборот >100/мес) хранится в зоне FAST_PICK, C-категория — в BULK_STORAGE
4. **Кросс-номера** — при отсутствии оригинала система предлагает аналоги с фиксацией замены в заказе
5. **Приоритеты заказов** — URGENT требует комплектации в течение 30 минут от подтверждения
6. **Сертификаты качества** — партия без действующего сертификата автоматически помещается в QUARANTINE
7. **Отмена заказа** — возможна только до начала комплектации (до статуса PICKING)
8. **Wave picking** — групповая комплектация нескольких заказов по оптимальному маршруту
9. **Замена на аналоги** — фиксируется в заказе (requestedOem vs providedOem)


## Тестовые сценарии

1. **Успешный заказ** — создание запчасти → добавление кросс-номеров → приёмка партии → создание заказа с VIN → подтверждение → резервирование → комплектация → отгрузка
2. **Замена на аналог** — недостаток оригинала → предложение кросс-аналога → замена → комплектация
3. **Несовместимость по VIN** — попытка добавить запчасть для другой марки → IncompatiblePartException
4. **Недостаток остатков** — попытка зарезервировать больше, чем есть → InsufficientStockException
5. **Просроченный сертификат** — приёмка партии с истёкшим сертификатом → помещение в QUARANTINE
6. **Срочный заказ** — URGENT-заказ → проверка времени комплектации < 30 минут → иначе логирование нарушения SLA
7. **ABC-перемещение** — изменение оборота запчасти с 50 до 150/мес → пересчёт категории B→A → перемещение в зону FAST_PICK
